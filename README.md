# Enterprise agents: opportunity, value evidence, and architecture

A dependency-free, interactive guide designed for GitHub Pages. It starts with an opportunity-and-evidence whiteboard, then progresses through the enterprise architecture required to build, connect, govern, operate, and measure the selected agent scenario.

## Run locally

Open `index.html` in a modern browser. No build, package installation, or server is required.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its default branch.
2. In **Settings** → **Pages**, choose **Deploy from a branch**.
3. Select the default branch and the **/(root)** folder.
4. Save. GitHub Pages publishes `index.html` as the site entry point.

## Accessibility and interaction

- Board 1 frames the business opportunity, appropriate agentic pattern, and value-evidence loop.
- Board 2 reveals the enterprise architecture progressively as top-to-bottom layers: where work happens, where agents are built, how agents connect safely, what agents can use, where trusted business data lives, and estate-level governance with Agent 365, closing with a handoff back to the Board 1 value loop.
- Every diagram element is keyboard-focusable and opens a concise role explanation with role, why it appears, and an accurate caveat.
- Customer question scenarios dim the rest of Board 2, highlight the responsible layers in stable category colors, and number the route so the answer can be read straight off the board.
- The visual drawing effect honors `prefers-reduced-motion`.
